tabler-page {tabler}R Documentation

Create a Tabler Dashboard Page

Description

Main function to create a complete dashboard page with Tabler theme

Usage

page(
  title = NULL,
  navbar = NULL,
  body = NULL,
  footer = NULL,
  layout = "boxed",
  theme = "light",
  color = "blue",
  font = "sans-serif",
  base = "gray",
  radius = "1",
  show_theme_button = FALSE
)
topbar(title = NULL, brand_image = NULL, ...)
footer(left = NULL, right = NULL)
sidebar_menu(..., title = NULL)
horizontal_menu(...)
menu_item(text, tab_name = NULL, icon = NULL, href = NULL, badge = NULL)
tab_items(...)
tab_item(tab_name, ...)

Arguments

title App title
navbar Dashboard navbar/menu. Can be: - 'sidebar_menu()' for a vertical sidebar - 'horizontal_menu()' for a horizontal menu
body Dashboard body content
footer Dashboard footer (optional)
layout Layout type: "boxed" (default), "combo", "condensed", "fluid", "fluid-vertical", "horizontal", "navbar", "navbar-dark", "navbar-overlap", "navbar-sticky", "navbar-sticky-dark", "rtl", "vertical", "vertical-right", "vertical-transparent"
theme Default theme: "light" (default) or "dark".
color Color theme (optional): "blue" (default), "azure", "indigo", "purple", "pink", "red", "orange", "yellow", "lime", "green", "teal", "cyan".
font Font family: "sans-serif" (default), "serif", "monospace", "comic".
base Theme base/gray shade: "gray" (default), "slate", "zinc", "neutral", "stone".
radius Corner radius factor: 1 (default), 0, 0.5, 1.5, 2.
show_theme_button Whether to show the theme toggle buttons in the navbar and the floating theme settings customizer panel (color mode, color scheme, font family, theme base and corner radius). Default 'FALSE'.
brand_image URL or path to brand image
... Additional header content (e.g., nav items)
left Left-aligned content
right Right-aligned content
text Item text/label
tab_name Tab name for routing
icon Icon name (optional)
href Link URL (optional, alternative to tab_name)
badge Badge text (optional)

Value

HTML tag with dependencies attached

Examples

ui <- page(
  title = "Combo Dashboard",
  layout = "combo",
  navbar = list(
    top = topbar(title = "My App"),
    side = sidebar_menu(
      menu_item("Dogs", icon = "dog"),
      menu_item("Cats", icon = "cat")
    )
  ),
  body = body("Welcome to Tabler!")
)

server <- function(input, output, session) {}
